# Startup plan: product links to social posts

An editable plan for the 14-stage startup journey, plus an automation priority list and workflow map.

## Idea
Turn ecommerce product links into ready-to-publish social posts. First segment to validate: small Shopify and Etsy sellers.

## Use it
1. Open `index.html` in a browser. No install or server needed.
2. **Plan** tab: for each stage, set status, edit the decision and open question, click each criterion to cycle open, pass, fail, and add evidence notes.
3. **Automations** tab: rate each workflow 1-5; the ranking updates.
4. Edits save in your browser (localStorage). Use **Export JSON** to back up, **Reset** to start over.

## Files
- `index.html` - plan, flow rail, automation list and workflow map
- `requirements.md` - what the plan tool and the product MVP must do
- `tasks.md` - ordered next steps with owners and pass/fail gates

## Rules of the plan
- Only mark a stage Passed when its criteria have evidence in the notes.
- Spend in stages; do not fund the next stage until the current gate passes.
- Numbers in the plan are targets to test, not forecasts.
